# Порядок — веб-клиент (React + Vite)

Реальный фронтенд «Главной», **воссозданный по дизайн-исходнику** `.dc` (тёплая
«бумага», тема kodawari-light) и привязанный к бэкенду — не компилированный
билд из Claude Design, а отдельный кодовый проект, который не затирается
ре-экспортом.

## Что внутри (ядро «Главной»)

- **Чек-ин → фокус:** энергия (Тихо / Ровно / На подъёме) × время (15/30/60) →
  одна задача под состояние; «Сделано» → следующая; когда дел нет — спокойный
  энсо «Все дела в порядке. Ты молодец — можно отдыхать».
- **Задачи дня** с тихим завершением и разделом «Сделано сегодня».
- **Быстрый захват** → в задачи или в Мысли.
- **Тёплое касание** — из `GET /suggestions/touches` (остывшие клиенты).
- **Недавнее** — лог активности.
- **Экран входа** (email+пароль → JWT), адрес сервера настраивается.

Данные грузятся через `GET /state`, изменения сохраняются debounced-`PUT /state`
(бэкенд мёржит по присутствию ключей, поэтому шлём весь bundle).

## Запуск

```bash
cd frontend/web
npm install
npm run dev          # http://localhost:5173
```

Бэкенд должен быть поднят (см. корневой README). На экране входа: `demo@poryadok.app` /
`poryadok`; если API не на `http://localhost:8000` — раскрой «Сервер» и впиши адрес.

```bash
npm run build        # типчек (tsc) + продакшен-сборка в dist/
npm run preview      # отдать собранный dist локально
```

Адрес API по умолчанию можно зашить на сборку через `VITE_API_BASE`.
