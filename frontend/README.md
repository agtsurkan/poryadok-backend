# Фронтенд «Порядок»

Два пути подключения фронта к бэкенду — оба рабочие, под разные задачи:

- **`web/`** — **реальный React + Vite-проект**, «Главная» воссоздана по дизайн-
  исходнику `.dc` (тёплая «бумага») и привязана к API. Durable: отдельный кодовый
  проект, переживает ре-экспорт из Claude Design, расширяется на глубокие разделы.
  → запуск в `web/README.md`. **Рекомендуемый путь.**

- **`bridge/`** — быстрый **мост на экспортированный билд**: патчер (`wire_api.py`)
  врезает логин + `GET/PUT /state` вместо `localStorage` в standalone-выгрузку
  Claude Design. Пиксельно тот же дизайн и работает сразу, но это компилированный
  билд (затирается ре-экспортом — патчер прогоняется заново). → `bridge/README.md`.

Бэкенд для обоих — в корне репозитория (см. корневой `README.md`). CORS включён.
