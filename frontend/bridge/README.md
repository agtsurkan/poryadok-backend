# Фронт — провязка с API (мост P0)

Здесь лежит **мост** между standalone-экспортом из Claude Design и бэкендом:
вместо `localStorage` сборка ходит в `GET/PUT /state` и логинится.

- `wire_api.py` — патчер: врезает мост в любой экспорт (переиспользуемый).
- `poryadok.html` — готовая провязанная сборка (можно открывать прямо сейчас).

## Как пользоваться

1. Подними бэкенд локально (см. корневой README) — он слушает `http://localhost:8000`.
2. Открой `frontend/poryadok.html` в браузере (двойным кликом / `file://`).
3. На экране входа: `demo@poryadok.app` / `poryadok`. Если сервер не на localhost —
   раскрой «Сервер» и впиши адрес. После входа приложение тянет данные с сервера и
   сохраняет туда же (debounced).

> Для нескольких устройств: задеплой бэкенд (см. корневой README) и впиши его адрес в
> поле «Сервер» на входе.

## Перепровязать новый экспорт

Ты продолжаешь дизайнить в Claude Design и переэкспортируешь сборку — просто прогони
патчер заново (мост идемпотентен и хранится здесь, в гите):

```bash
python frontend/wire_api.py "путь/к/новому-export.html" -o frontend/poryadok.html
```

## Как устроен мост

Маленький `<script>`, вставленный **перед** бандлером:

- **Вход** — `POST /auth/login {email,password}` → JWT (в `localStorage['poryadok.token']`).
- **Гидрация** — `GET /state` отдаётся приложению через перехват
  `localStorage.getItem('poryadok.data')` (синхронно, чтобы `componentDidMount` увидел
  серверные данные).
- **Сохранение** — перехват `localStorage.setItem('poryadok.data', …)` зеркалит запись в
  `PUT /state` (debounced). `401` → разлогин.

## Известные ограничения (осознанно, для моста)

- Эта сборка сохраняет только `tasks/inbox/events/events2/quickLinks/services/links`.
  `projects/clients/directions` она не персистит (баг фронта, бриф §11.1) — **бэкенд их
  хранит корректно** (merge по присутствию ключей, частичный сейв их не трёт), просто эта
  сборка не показывает серверные копии. Долговременная правка — в исходнике `.dc`.
- Гидрация использует синхронный XHR (нормально для локального моста; в `.dc`-версии будет
  async).
- `file://` → `http://localhost` работает. Если страницу отдавать по `https`, бэкенд тоже
  должен быть `https` (иначе mixed-content).
